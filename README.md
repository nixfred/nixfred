## The collaborator

AI tools get more useful when the context survives the conversation. My public work here covers persistent memory, local models, desktop visibility and agent handoffs.

- **[LMF4.1](https://github.com/nixfred/lmf4.1)**: persistent memory for Claude Code, with searchable sessions, decisions and learnings.
- **[Claude on Mac](https://github.com/nixfred/claude-on-mac)**: Apple ecosystem tools for Claude Code, with consent controls for sending messages and mail.
- **[Local Intelligence](https://github.com/nixfred/omarchy-local-intelligence)**: Ollama monitoring and model controls from the Omarchy bar.
- **[PR Hunter](https://github.com/nixfred/pr.hunter)**: inspect GitHub work and hand a brief to an existing agent.
- **[Burnbar](https://github.com/nixfred/burnbar)**: Claude and Codex token-use visibility on the bar.

I also keep forks of **[firstmate](https://github.com/nixfred/firstmate)** ([kunchenguid](https://github.com/kunchenguid/firstmate)), **[slopbrake](https://github.com/nixfred/slopbrake)** ([GreyforgeLabs](https://github.com/GreyforgeLabs/slopbrake)) and **[nixfredOS](https://github.com/nixfred/nixfredOS)**, a fork of the open source LifeOS project (MIT). Their upstream authors deserve the credit. A fork's recent push date is not a claim that I authored every change.
