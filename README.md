# Hey, I'm Fred.

**I build on Omarchy, connect machines, and give AI collaborators a memory.**

Native Linux tools. Useful automation. Interfaces with a little electricity.

**[Explore the plugins](https://omarchy.nixfred.com)** · **[Browse every public project](PROJECTS.md)** · **[GitHub](https://github.com/nixfred)**

## Start here

Six entry points into what I've been building lately. Each links to its own source, documentation and installation instructions.

| Project | The idea |
| :--- | :--- |
| **[Glide](https://github.com/nixfred/Glide)** | **One desk. Every machine.** Move your mouse and keyboard between Omarchy computers on the LAN. Powered by [Lan Mouse](https://github.com/feschber/lan-mouse). |
| **[Pulse](https://github.com/nixfred/pulse)** | **Find the bottleneck.** CPU, memory, storage, network and GPU monitoring in one Omarchy bar widget. |
| **[Omarchy Doctor](https://github.com/nixfred/omarchy-doctor)** | **See the evidence.** System diagnostics, live graphs, findings and an explicit handoff to your coding agent. |
| **[Imprint](https://github.com/nixfred/imprint)** | **Take your desktop with you.** Save a selectable desktop recipe, then preview and restore it on another working Omarchy installation. |
| **[Infomarchy](https://github.com/nixfred/infomarchy)** | **Put the context in view.** AI sessions, activity and machine information on your wallpaper. |
| **[Blip](https://github.com/nixfred/blip)** | **Messages meet Linux.** iMessage in the Omarchy bar, with your Mac acting as the gateway. |

## The collaborator

AI tools get more useful when the context survives the conversation. My public work here covers persistent memory, local models, desktop visibility and agent handoffs.

- **[LMF4.1](https://github.com/nixfred/lmf4.1)** — persistent memory for Claude Code, with searchable sessions, decisions and learnings.
- **[Claude on Mac](https://github.com/nixfred/claude-on-mac)** — Apple ecosystem tools for Claude Code, with consent controls for sending messages and mail.
- **[Local Intelligence](https://github.com/nixfred/omarchy-local-intelligence)** — Ollama monitoring and model controls from the Omarchy bar.
- **[PR Hunter](https://github.com/nixfred/pr.hunter)** — inspect GitHub work and hand a brief to an existing agent.
- **[Burnbar](https://github.com/nixfred/burnbar)** — Claude and Codex token-use visibility on the bar.

I also keep forks of **[firstmate](https://github.com/nixfred/firstmate)** ([kunchenguid](https://github.com/kunchenguid/firstmate)), **[slopbrake](https://github.com/nixfred/slopbrake)** ([GreyforgeLabs](https://github.com/GreyforgeLabs/slopbrake)), and **[nixfredOS](https://github.com/nixfred/nixfredOS)** ([Daniel Miessler's LifeOS](https://github.com/danielmiessler/LifeOS)). Their upstream authors deserve the credit. A fork's recent push date is not a claim that I authored every change.
